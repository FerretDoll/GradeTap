## 后续归档约定

- 新材料按用途放入对应目录，并在本页添加入口。
- 文件名优先使用“项目或主题_材料名称_版本”，日期或版本只使用材料中可以确认的信息。
- 同主题的不同版本保留明确标识；预览文件与可编辑源文件放在一起。
- 移动或重命名材料时，同步更新本页与引用它的文档。
